Pilot #0 — Meerada on its own maker

First real-data run: Trybe's live Teeby / group-agent traffic · 2026-08-28 · all content stayed on the machine
The headline: the full pipeline ran end-to-end on 469 real production LLM calls — and Meerada then correctly refused to grade or migrate them. Trybe's warm-chat assistant has almost no programmatic verification, so 76% of tasks are unknown and the golden set is empty. That is not a failure — it is the product proving its integrity, exactly as the spec predicted. Trybe validated the engine; it is not itself a Handshake customer.

What actually ran

✓
Collect & normalize
569 messages pulled from agent_messages + teeby_space_messages, normalized to 469 metadata-only traces. Every message body stayed local — the exported events carry only salted fingerprints, token estimates and timings.
✓
Grade (CPAT report)
426 tasks assembled, real CPAT and waste computed, ranked report rendered.
✓
Extract taxonomy
12 task clusters discovered by HDBSCAN from real traffic shape — a genuine map of what Teeby does.
✕
Handshake — correctly blocked
Golden sets came back empty: the builder admits only grade-A measured cases, and Trybe has zero. Nothing to replay on a candidate model. Meerada did not invent a migration it couldn't prove.

All of the estimated waste is uncached repeated context — Teeby re-sends its ~3k-token system prompt on every call. Trybe's own edge function already caches it above 3,500 chars; Meerada independently flagged the same leak from metadata alone. Retry and dead-task waste are $0 because there are no measured failures.

What a real Handshake pilot needs next

The right first customer is a verifiable workload — code generation with tests, structured extraction with schemas, or agents with tool-call contracts — where 50%+ of tasks carry a measured signal. Trybe could become one narrow slice at a time: if Teeby emitted a JSON action-envelope (it already uses action tags), those calls would become measured and a real Handshake from claude-haiku-4-5 to a cheaper candidate would become possible — with a real gap report.
