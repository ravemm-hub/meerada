💱 Outcome Exchange — buy a done task, not tokens

This is what makes the arena a real market. Post the job and the quality bar; the exchange routes to the cheapest model that clears it. The price is the live CPAT — cost per verified task. As grades move, the clearing price moves. prototype
🧭 The Bourse in 30 seconds
1 · Every hour we run the same verifiable tasks (schema, regex, unit-checkable) on every model we can reach, and check the outputs by program — not by opinion.
2 · Each model gets a grade (verified success rate, with its confidence interval) and a price: what one verified task cost at the provider's public list price — CPAT — plus how long it took (TTAT).
3 · You post a job and a quality bar. The exchange clears at the cheapest model over the bar. That clearing price is the market price of a done task — and it moves as models change.
Why only a middleman can run it: pricing a "done task" needs independent verification across every vendor. A vendor can't grade itself; a token reseller doesn't verify. The interface people work through (LLManager) is where that measurement comes from and where the routing gets applied.

🧪 The test battery — what actually moves a grade

No opinions, no vibes. Every model runs the same programmatically-checkable tasks. Light tests run constantly so the grade stays fresh; heavy tests run less often but weigh more. Hundreds of these micro-checks roll up into the category scores, and the categories into the single grade — that's how small, checkable tasks extrapolate to a macro verdict you can trust.
⚡ LIGHT — fast, high-frequency, keep the grade current
🏋 HEAVY — complex, weighted, the real separators
Live pass-rates update as tests run above. A test is scored only when its output is machine-verifiable — code that must pass hidden asserts, JSON whose totals must add up, a retrieval whose cited fact must be exact. That's what separates a Meerada grade from a leaderboard vote.
