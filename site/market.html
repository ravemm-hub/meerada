The quality guarantee. A cheaper model only "passes" if its output is equivalent to your current model's proven-good output — field-for-field on JSON, same tests on code, same value in text. A model that's cheaper but changes an answer is flagged BLOCK, never sold as a win.
Every grade rests only on tasks we can check programmatically — no opinion. These are the verifiable task families; each model runs many instances, and each output is verified automatically.
Why only verifiable tasks: a benchmark you can't check is a guess. Meerada scores the transactional unit — a task that measurably succeeded — so a grade means "this model did real, checkable work for this cost," with a confidence interval.
