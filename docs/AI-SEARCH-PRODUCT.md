# Meerada Search — "מה ה-AI מראה" כמנוע חיפוש ציבורי, והמשפך לעסקים

תכנון, 25.11.2026, בעקבות כיוון המייסד: אתר שבו כל אחד מחפש מה שבא לו ורואה את התוצאות **כפי שמנועי
ה-AI מציגים אותן לכולם**, מדורגות לפי מה שה-AI רואה, ומתחת: "העסק שלך לא כאן? הכנס אותו וקבל את הכלים
לעלות". מודל גוגל, אבל מכוון לחיפושי ה-AI; בסגנון Alexa Rank: דירוג ציבורי שכולם מצטטים.

## 1. למה זה עובד — ולמה דווקא עכשיו
- **יש לנו כבר את המנוע.** ה-Search Lab שואל 5 מנועים, מחלץ מי נקוב, מאיפה, כמה פעמים, ומחזיק 141 תשובות
  שגדלות כל יום. מה שחסר הוא תיבת חיפוש מול המשתמש, שכבת cache, דירוג-קונצנזוס ומשפך הרשמה.
- **המשפך הוא טבעי.** בעל עסק מחפש את הקטגוריה שלו, רואה שהוא לא ברשימה הקצרה של ה-AI (ככה זה ל-98%
  מהעסקים, SOCi: ChatGPT ממליץ על 1.2% מהמיקומים), ולוחץ "זה העסק שלי". זה רגע כאב אמיתי, לא שיווק.
- **אפקט הגלגל.** כל עמוד שאילתה שלנו ("plumber in Tel Aviv — what the AI engines show") הוא עמוד השוואה
  ניטרלי, טרי, מובנה, עם עובדות — בדיוק סוג העמוד שהמנועים מצטטים. ככל שיש יותר עמודים כאלה, המנועים
  מצטטים אותנו יותר, יותר עסקים מגיעים דרכם, יותר נתונים. זה ה-flywheel של גוגל בהיפוך: אנחנו גם המודד
  וגם מקור שהמנועים קוראים.
- **אין מתחרה בצורה הזו.** 30+ כלי GEO הם דשבורדים למשווקים; אף אחד לא נותן למשתמש אנונימי לחפש ולראות
  "מה ה-AI אומר", ואף אחד לא מפרסם לפני/אחרי. HubSpot AEO Grader הכי קרוב — ציון למותג, בלי תוצאות.

## 2. המוצר בשלושה מסכים
1. **חיפוש.** תיבה אחת. המשתמש מקליד כל דבר ("רופא שיניים בחיפה", "best CRM for a small agency", "מלון
   בלונדון עד 200 פאונד"). אם השאילתה (או קרובה לה) כבר במאגר — תוצאות מיידיות. אם לא — ריצה חיה ב-3
   מנועים (ChatGPT, gpt-5-mini, Claude; Perplexity כשיש קרדיטים) עם מד התקדמות של 15–30 שניות, ושמירה
   למאגר. כל ריצה גם מזינה את ה-Search Lab.
2. **תוצאות "לפי ה-AI".** רשימה מדורגת לפי **ציון קונצנזוס**: בכמה מנועים ובכמה ריצות העסק נקוב, באיזה
   מיקום בתשובה, האם האתר שלו צוטט. לכל תוצאה: אילו מנועים נקבו בו, מאילו מקורות (Maps / easy / Yelp /
   best-of), הציטוט המקורי בלחיצה, ציון הנוכחות שלנו (audit) אם יש אתר. לצד: **עמודת גוגל** (מיקום ב-Maps
   לאותה שאילתה) כדי להראות את הפער — החפיפה בין גוגל ל-AI היא ~20% בלבד, וזה הסיפור של המוצר. למטה:
   "מי שלא כאן לא קיים ל-AI".
3. **"זה העסק שלי" / "העסק שלי לא כאן".** זיהוי בשלושה שדות (שם, טלפון, אתר) → אימות בוואטסאפ (ה-OTP של
   מירה כבר חי) → **דוח חינמי**: איפה אתה מופיע ואיפה לא, מה המנועים קוראים בקטגוריה שלך, ציון הנוכחות
   והתיקונים לפי סדר (audit v0), ומה המתחרים שכן נקובים עושים אחרת (עובדות: אתר נטען, מחירים, Yelp,
   easy, מדריכים) → **מנוי**: מעקב שבועי על השאילתות שלו, תיקונים מבחוץ שאנחנו מבצעים (מדריך, פרופיל,
   אזכורים), הנחיות לתיקוני בעלים (אתר, GBP, Yelp), ומקרה מבחן ציבורי באישור. רף האיכות של §13 בתוקף:
   מי שמתחת לרף מקבל הנחיות, לא קידום.

## 3. ציון הקונצנזוס (הדירוג שלנו)
score(עסק, שאילתה) = Σ על המנועים של w_engine × (נקוב בריצה / ריצות) × (1 / מיקום בתשובה)^0.5, פלוס בונוס
קטן כשאתר העסק מצוטט. w_engine לפי נתח השימוש הצרכני (ChatGPT גבוה). כל ציון מוצג עם n (ריצות) ותאריך.
הדירוג **לא למכירה**; Promoted, אם יהיה, בבלוק נפרד ומסומן. בלי כוכבים משלנו. זה "Alexa Rank" לנראות AI.

## 4. ארכיטקטורה (על מה שקיים)
- **מנוע שאילתות:** `handover.visibility.engines` + `extract` + `features` כפי שהם, עטופים ב-API קטן
  (FastAPI כבר בפרויקט; Render כבר מריץ את ה-hosted tester) עם: תור, cache לפי שאילתה מנורמלת, תקרת תקציב
  יומית קשה (DailyBudget), rate-limit לאנונימיים (3 חיפושים חיים ביום, בלי הגבלה ל-cache), CAPTCHA-free
  (בלי בוטים דרך IP+cookie בלבד; אם ננצל — token קטן).
- **מאגר:** Postgres (Supabase של מיראדה): queries, answers (כמו visibility_state), businesses, claims,
  audits. ה-Search Lab היומי כותב לאותו מאגר.
- **עמודי שאילתה סטטיים:** כל שאילתה שנשאלה מספיק פעמים (או כל 138 שאלות המעבדה) מקבלת עמוד HTML קבוע
  ב-meerada.app/s/<slug> עם התוצאות, התאריך, המקורות ו-JSON-LD — נזחל, ב-sitemap, IndexNow. ערך אמיתי,
  לא 500 תבניות ריקות (מדיניות הספאם של גוגל).
- **עמודת גוגל:** Places API (New) Text Search לאותה שאילתה (צריך להפעיל את ה-API על המפתח — זו הפעולה
  שחסמה את בחירת העסקים; כאן היא הופכת הכרחית), או Google Custom Search JSON למוצרים/תוכנה.
- **הרשמה ותשלום:** זיהוי בוואטסאפ דרך מירה; תשלום דרך Paddle/Lemon Squeezy כ-merchant of record
  (Stripe לא בישראל; הערת payments-model), מחירון 29–99$ / 99–149 ₪.
- **ממשק:** דף אחד בעברית+אנגלית (international first), כהה-ראשון כמו שאר האתר, RTL אוטומטי.

## 5. כלכלה
- ריצה חיה = ~0.10$ (chatgpt 0.03 + gpt-5-mini 0.04 + claude 0.02 + perplexity 0.008). עם cache של 7 ימים
  לשאילתה, העלות היא לפי שאילתות ייחודיות: 1,000 שאילתות ייחודיות ביום = 100$ ביום. תקרה קשה 20$ ביום
  בהתחלה (200 ריצות חיות), השאר מה-cache + "הרץ עכשיו" למנויים.
- הכנסה: מנוי 29–99$ לחודש; יעד ראשון 100 מנויים = 3–10 אלף $ לחודש, מכסה את כל עלות המדידה פי 10.
- הגלגל: עמודי השאילתה מביאים תנועה חינמית (SEO + ציטוטי AI) → בעלי עסקים → מנויים → עוד נתונים.

## 6. מה שונה מגוגל ומה חייבים לפענח
- גוגל מדרג עמודים לפי קישורים ואיכות; המנועים **בוחרים ישויות** מתוך 5–10 מועמדים לפי אזכורים בצד שלישי,
  דירוג/ביקורות כשער, ומקורות קבועים לכל מנוע. החפיפה בין Top-10 של גוגל ל-Top-5 של AI נמוכה. המוצר
  מראה את הפער הזה לכל שאילתה, ומסביר אותו: "הנה למה X נקוב ואתה לא" — עובדות, לא ניחושים.
- פענוח שיטתי = ה-Search Lab: לכל שאילתה גם Google column, ועם הזמן מודל שמנבא "נקוב ב-AI" מתוך
  מאפיינים (§16 ב-PRESENCE-ENGINE). ככל שיש יותר שאילתות ממשתמשים אמיתיים, המודל טוב יותר — וזה החפיר.

## 7. סיכונים וגדרות
- עלות ובוטים → תקרה קשה, rate-limit, cache. איטיות → cache + סטרימינג + "נשלח לך בוואטסאפ כשמוכן".
- פער API–צרכני → מסומן בכל עמוד ("נמדד דרך ממשקי ה-API של המודלים עם חיפוש רשת; האפליקציות הצרכניות
  עשויות להיות שונות") + וריאנט fan-out. סימנים מסחריים → "מה ChatGPT ענה" בציטוט, לא לוגו שלהם.
- תוכן על עסקים → עובדות ציבוריות בלבד, ערוץ תיקון, בלי כוכבים משלנו (DMCC/FTC/חוק הגנת הצרכן, §4).
- חוות עמודים → רק שאילתות שנשאלו באמת או שנמדדו במעבדה, עם ערך (תוצאות, מקורות, תאריך).

## 8. MVP בשבוע
1. API `/api/search?q=` על Render: cache → ריצה חיה בתקרה → JSON (קונצנזוס, מנועים, מקורות, ציטוטים).
2. דף `search.html`: תיבה, תוצאות, עמודת "לפי ה-AI", בלוק "זה העסק שלי / העסק שלי לא כאן".
3. 138 שאילתות המעבדה כעמודים סטטיים ב-/s/ מהיום הראשון (יש נתונים), sitemap + IndexNow.
4. "זה העסק שלי" → וואטסאפ OTP (קיים) → דוח חינמי (audit v0 + איפה מופיע) → רשימת המתנה למנוי.
5. עמודת גוגל — ברגע שה-Places API פתוח.
6. תשלום (Paddle) — שבוע 2. מדידת המשפך מהיום הראשון (חיפושים → קליק "זה העסק שלי" → OTP → דוח → מנוי).

## 9. מה צריך ממך
- אישור להתחיל את ה-MVP (זה פרויקט של כשבוע, מעל ה-Search Lab).
- להפעיל Places API (New) על מפתח גוגל — עמודת גוגל היא לב ההשוואה.
- קרדיטים ל-OpenRouter (Perplexity) ומפתח Gemini — כדי שהחיפוש יציג 5 מנועים ולא 3.
- החלטת שם למוצר הציבורי (עבודה: Meerada Search / "What the AI shows").
