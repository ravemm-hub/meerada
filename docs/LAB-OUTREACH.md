# Lab outreach — asking the labs for grading credentials

Goal: every major lab measured hourly on Meerada with the lab's blessing —
credits or a research key for *measurement only*, and in return a neutral,
public, reproducible number they can point to. Send from your own address; keep
it short; attach nothing. The exchange link is the pitch.

## The email (EN) — one per lab, change the bracketed bits
Subject: Measurement-only API access for a public, reproducible model ranking

> Hi [name / team],
>
> I run Meerada (https://meerada.app), a public exchange that grades every AI model it can reach **every hour** on a battery of tasks a program verifies — hidden unit tests, SQL against a real database, exact answers, faithful summaries, agentic tool plans, safety refusals — and prices each model by cost per verified task. Grades come only from programmatic checks; the battery and the checkers are open-source (Apache-2.0), so anyone can rerun them.
>
> [Model] is currently [not on the board / measured on a small budget], because I grade on my own keys. I'd like to measure it properly: ~[N] verified tasks per day, at a cost of roughly $[X]/day at list price.
>
> I'm asking for a measurement-only key or credits for that volume. In return: a neutral public number on the exchange (no lab is ever graded by its own family; sponsored grading buys measurement, not results), a lab page with your models and links, and the raw per-cluster results for your team. Results publish either way — that is the whole point.
>
> Happy to share the exact task list and the checker code first.
>
> Rave Maymon · Meerada · https://meerada.app · https://github.com/ravemm-hub/meerada

## Follow-up rules
- One follow-up after 10 days, then stop. Post the measured numbers anyway.
- Never accept conditions on what gets published. Credits for measurement only.
- Log every reply in this file (date, lab, outcome) so the next person knows.
